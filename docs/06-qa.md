## 5. Coverage statement

Coverage is **measured only for pure business logic by test inventory**, not by a coverage tool:

- `src/lib/pricing.ts` — 5/5 branches covered (sale, percent, fixed, expired, shipping).
- `src/lib/admin-rules.ts` — all predicates covered, including self/super-admin protection.
- `src/lib/rate-limit.ts` — allow/block/isolation/window/seconds covered.
- `orders.functions.ts`, `admin.functions.ts`, `catalog.functions.ts` — **not unit-covered**
  (network + Supabase). These are the 80 % gate risk; the fix is an integration test against a
  disposable Supabase project.

**Quality gate 3 (80 % business logic) is therefore NOT certified.**
